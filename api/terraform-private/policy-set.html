Platform environment
Platform environment mode executes policies directly in HCP Terraform or Terraform Enterprise. This mode currently uses Sentinel 0.40.x. Use this mode if you have Sentinel policies that need access to cost estimation data and granular policy enforcement of soft and hard mandatory.
HCP Terraform Agent
The HCP Terraform Agent runs policy sets in an isolated environment (private agent) and evaluates them with a pinned runtime version.
HCP Terraform Agent based policy set evaluations don't have access to cost estimation data.
Runtime version
This policy set uses the latest Sentinel version and does not upgrade automatically. To upgrade, select a newer version.
