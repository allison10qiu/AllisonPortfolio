# White Wing cursor set — site notes

Original files from `white-wing-s-by-mei.zip` are kept unmodified in this folder
(set by NaLexnu ♡♥ on rw-designer.com, license: Creative Commons Attribution +
Noncommercial — see `readme.txt`).

`link-select-static.cur` is the only added file. Browsers cannot render `.ani`
cursors, so it is frame 2 of `Link Select.ani` extracted unchanged (32×32,
hotspot 0,0) to serve as the link cursor. Frame 1 of that animation is
pixel-identical to `Normal.cur`, so frame 2 is used because it is the one that
visibly differs from the default pointer.
